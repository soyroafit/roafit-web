# Recursos de imagen ROAFIT

Esta carpeta queda reservada para el logotipo y las fotografías reales de ROAFIT. No se han añadido imágenes de stock ni imágenes generadas.

## Logotipo y fondo de portada

- Guarda el logotipo oficial en PNG como `roafit-logo.png`. El encabezado, el hero y el pie de página lo mostrarán automáticamente; mientras falte, permanece el logotipo tipográfico provisional.
- Guarda la fotografía de fondo de portada como `hero-background.jpg`. La capa oscura se aplica automáticamente. Para cambiarla más adelante, sustituye ese archivo conservando el nombre o modifica `--home-hero-image` en `assets/css/site.css`.

## Espacios reservados para fotografías

- Método: tres fotografías, una por tarjeta, proporción 16:9.
- Retrato del coach: proporción 3:4.
- Galería de inicio: una imagen principal y dos secundarias, proporción 16:9.
- Herramientas, comunidad y tienda: se conservan sus espacios visuales existentes.

Los bloques de fotografía siguen siendo espacios vacíos accesibles. Cuando aportes esas imágenes, se podrán colocar en sus espacios sin usar fotos de stock ni generadas.
